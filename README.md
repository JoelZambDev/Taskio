# Taskio 📝

**Taskio** is a lightweight, responsive web application for task management and personal productivity. Built entirely on vanilla frontend technologies, it allows users to organize daily activities, track pending items, and manage automated email reminders without requiring a dedicated backend server.

---

## ✨ Core Features

* **Task Management:** Create, edit, classify, and mark tasks as complete with a clean interface.
* **Local Persistence (LocalStorage):** Saves your tasks directly in the browser so your data persists across page reloads.
* **Email Notifications:** Automated reminders and alerts sent directly through **EmailJS** integration.
* **Interactive UI:** Includes an interactive calendar layout for tracking task deadlines.
* **Fully Responsive Design:** Optimized layout for seamless navigation on both mobile and desktop screens.

---

## 🛠️ Built With

* **HTML5:** Semantic markup and document structure.
* **CSS3:** Custom styling, layout design, and smooth interface transitions.
* **JavaScript (ES6+):** Client-side application logic, DOM manipulation, and LocalStorage state management.
* **EmailJS:** Third-party API for sending notification emails directly from the client side.
